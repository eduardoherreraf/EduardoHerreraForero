Conceptos Básicos de Machine Learning

El machine learning, o aprendizaje automático, es una rama de la inteligencia artificial que permite a los sistemas informáticos aprender a partir de datos sin ser programados explícitamente para cada tarea. En lugar de seguir instrucciones codificadas paso a paso, los algoritmos identifican patrones en grandes conjuntos de datos y los utilizan para hacer predicciones o tomar decisiones. Este campo ha transformado industrias como la salud, las finanzas, el entretenimiento y el transporte, impulsando la innovación y la eficiencia.

¿Qué es el machine learning?

El machine learning (aprendizaje automático) es una rama de la inteligencia artificial que permite que un sistema aprenda patrones a partir de datos y utilice lo aprendido para realizar predicciones o tomar decisiones, sin tener que programar de manera explícita cada una de las reglas necesarias para resolver el problema.

En términos sencillos, en lugar de indicarle al computador todas las reglas que debe seguir, se le proporcionan ejemplos para que encuentre por sí mismo los patrones que existen en los datos.

El proceso básico puede entenderse en tres momentos:

  • Entrenamiento: se proporciona al algoritmo un conjunto de datos de entrenamiento. a partir de estos ejemplos, el algoritmo busca patrones y relaciones que le permitan resolver la tarea planteada.
  • Aprendizaje: mediante el entrenamiento, el algoritmo ajusta sus parámetros internos para representar los patrones encontrados en los datos. el resultado de este proceso es un modelo entrenado.
  • Predicción: el modelo entrenado recibe datos nuevos que no utilizó durante el entrenamiento y utiliza lo aprendido para realizar una predicción, clasificación o estimación.

Por ejemplo, si se quiere desarrollar un sistema que identifique si una imagen contiene un gato, se pueden proporcionar miles de imágenes previamente clasificadas. Durante el entrenamiento, el modelo aprende características y patrones presentes en esos ejemplos. Posteriormente, puede recibir una imagen nueva y estimar si contiene un gato, aunque esa imagen específica no haya formado parte de los datos de entrenamiento.

La importancia de los datos

La calidad de los datos es fundamental para obtener buenos resultados. tener muchos datos no garantiza que un modelo sea bueno. si los datos contienen errores, información incompleta, valores incorrectos, sesgos o información que no representa adecuadamente el problema real, el modelo puede aprender patrones equivocados.

Por esta razón, en machine learning es tan importante recopilar, limpiar, analizar y preparar correctamente los datos como seleccionar y entrenar el modelo.

Relación con la inteligencia artificial y el deep learning

Los términos inteligencia artificial (AI), machine learning (ML) y deep learning (DL) están relacionados, pero no significan lo mismo. La forma más sencilla de entenderlos es como tres niveles que se encuentran uno dentro de otro:

  • Inteligencia artificial (AI): es el campo más amplio. busca desarrollar sistemas capaces de realizar tareas que normalmente requieren capacidades asociadas con la inteligencia humana, como aprender, razonar, reconocer patrones, comprender lenguaje o tomar decisiones.
  • Machine learning (ml) o aprendizaje automático: es una rama de la inteligencia artificial. en lugar de programar manualmente todas las reglas, permite que los sistemas aprendan patrones a partir de datos y utilicen lo aprendido para realizar predicciones o tomar decisiones.
  • Deep learning (dl) o aprendizaje profundo: es una rama del machine learning que utiliza principalmente redes neuronales artificiales con múltiples capas para aprender patrones complejos. ha sido especialmente importante en áreas como el reconocimiento de imágenes, el procesamiento del lenguaje, el reconocimiento de voz y otras aplicaciones avanzadas.

Tipos de machine learning

Existen tres categorías principales, cada una con un enfoque y una aplicación diferentes.

Aprendizaje supervisado

El algoritmo se entrena con un conjunto de datos etiquetado: cada ejemplo incluye una "respuesta correcta". El objetivo es aprender a relacionar las entradas con las salidas a partir de esos ejemplos.

  • Clasificación: predice una categoría discreta. ejemplos: detectar correo no deseado (spam) o distinguir imágenes de gatos y perros.
  • Regresión: predice un valor continuo. ejemplos: estimar el precio de una vivienda o la temperatura del día siguiente.
  • Algoritmos frecuentes: regresión lineal y logística, árboles de decisión, random forest, k vecinos más cercanos (k-nn), máquinas de vectores de soporte (svm) y redes neuronales.

Aprendizaje no supervisado

Trabaja con datos sin etiquetar. El algoritmo debe descubrir por sí mismo patrones y estructuras ocultas, sin una guía externa.

  • Agrupamiento (clustering): agrupa datos similares en clústeres. se usa en la segmentación de clientes o en la organización de documentos. algoritmo frecuente: k-means.
  • Reducción de dimensionalidad: disminuye el número de variables conservando la información esencial. es útil para visualizar datos o mejorar el rendimiento de otros algoritmos. algoritmo frecuente: pca.
  • Detección de anomalías: identifica datos que se salen de lo normal, como transacciones sospechosas.

Aprendizaje por refuerzo

Un agente aprende a tomar decisiones interactuando con un entorno. Recibe recompensas por las acciones acertadas y penalizaciones por las erróneas, y con el tiempo desarrolla una estrategia que maximiza su recompensa total.

  • Aplicaciones: robótica, juegos (como alphago), control de recursos y algunos sistemas de recomendación.

Un cuarto enfoque: el aprendizaje semisupervisado

Combina una pequeña cantidad de datos etiquetados con una gran cantidad de datos sin etiquetar. Resulta útil cuando etiquetar es costoso, por ejemplo en imágenes médicas revisadas por especialistas.

El proceso de machine learning

El desarrollo de un modelo de machine learning es un proceso compuesto por varias etapas. Aunque el proceso puede variar según el proyecto, normalmente comienza con la definición del problema, continúa con la preparación de los datos y el entrenamiento del modelo, y termina con su evaluación, implementación y seguimiento.

  • Definición del problema: se establece qué se quiere resolver, qué variable se desea predecir o clasificar y cómo se determinará si el modelo está funcionando correctamente. por ejemplo, se puede buscar predecir las ventas de un producto o determinar si una transacción podría ser fraudulenta.
  • Recopilación de datos: se reúnen los datos necesarios para que el modelo pueda aprender. estos pueden proceder de bases de datos, archivos, sensores, aplicaciones, páginas web, apis u otras fuentes.
  • Preprocesamiento de los datos: los datos se limpian y transforman para que puedan ser utilizados por el modelo. esta etapa puede incluir la eliminación de duplicados, el tratamiento de valores faltantes, la corrección de errores, la normalización de variables y la conversión de datos categóricos a un formato que el modelo pueda interpretar.
  • División de los datos: los datos disponibles se separan normalmente en diferentes conjuntos. el conjunto de entrenamiento se utiliza para que el modelo aprenda; el conjunto de validación puede utilizarse para comparar configuraciones y ajustar el modelo; y el conjunto de prueba se reserva para comprobar su rendimiento final con datos que el modelo no ha utilizado durante el entrenamiento.
  • Selección del modelo: se elige el algoritmo más apropiado según el tipo de problema, los datos disponibles y los resultados que se esperan obtener. por ejemplo, se pueden utilizar algoritmos diferentes para clasificación, regresión o agrupamiento.
  • Entrenamiento: el algoritmo recibe los datos de entrenamiento y ajusta sus parámetros internos para aprender los patrones presentes en ellos. en términos sencillos, es la etapa en la que el modelo "aprende" a partir de los ejemplos proporcionados.
  • Evaluación: se comprueba qué tan bien funciona el modelo utilizando datos que no fueron utilizados para entrenarlo. para ello se emplean métricas adecuadas al problema, como accuracy, precision, recall, f1-score, mae o rmse.
  • Ajuste de hiperparámetros: se modifican determinadas configuraciones del algoritmo, conocidas como hiperparámetros, para intentar mejorar su rendimiento. este proceso debe realizarse cuidadosamente para evitar que el modelo termine sobreajustándose a los datos utilizados para la evaluación.
  • Despliegue: una vez que el modelo presenta un rendimiento adecuado, puede integrarse en una aplicación, sistema o proceso real para comenzar a generar predicciones sobre nuevos datos.
  • Monitoreo y mantenimiento: el trabajo no termina cuando el modelo se pone en funcionamiento. es necesario supervisar su rendimiento porque los datos y las condiciones del mundo real pueden cambiar con el tiempo. si el comportamiento de los datos cambia significativamente, puede ser necesario actualizar, volver a entrenar o incluso reemplazar el modelo.

Resumen del proceso

De forma sencilla, el proceso puede resumirse de la siguiente manera:

Problema → datos → preparación → división → modelo → entrenamiento → evaluación → ajuste → despliegue → monitoreo

Es importante entender que el proceso no siempre es completamente lineal. si durante la evaluación se descubre que el modelo no funciona adecuadamente, puede ser necesario regresar a etapas anteriores, mejorar los datos, seleccionar otro algoritmo o modificar la forma en que se preparan las variables.

Conceptos clave para evaluar un modelo

Evaluar un modelo de machine learning permite determinar qué tan bien aprende los patrones de los datos y, sobre todo, qué tan bien puede realizar predicciones sobre datos que no ha visto anteriormente. Para ello, existen varios conceptos y métricas fundamentales.

  • Sobreajuste (overfitting): ocurre cuando el modelo aprende los datos de entrenamiento de una manera demasiado específica, llegando incluso a memorizar el ruido, los errores y las particularidades de esos datos, en lugar de aprender los patrones generales. es como un estudiante que memoriza las respuestas de un examen de práctica y obtiene una excelente calificación en ese mismo examen, pero tiene dificultades cuando las preguntas cambian. un modelo sobreajustado suele presentar un rendimiento muy alto con los datos de entrenamiento, pero significativamente menor con datos nuevos.
  • Subajuste (underfitting): ocurre cuando el modelo es demasiado simple o no ha aprendido lo suficiente para representar adecuadamente los patrones presentes en los datos. es como intentar describir una curva compleja utilizando únicamente una línea recta. en este caso, el modelo suele presentar un rendimiento deficiente tanto con los datos de entrenamiento como con los datos nuevos.
  • Generalización: es la capacidad de un modelo para aplicar correctamente lo aprendido durante el entrenamiento a datos nuevos que no había visto anteriormente. un buen modelo no debe limitarse a memorizar los datos de entrenamiento, sino aprender patrones que puedan mantenerse cuando se enfrente a nuevos casos.
  • Métricas de clasificación: se utilizan cuando el modelo debe asignar una categoría o clase, por ejemplo, determinar si un correo es spam o no. entre las principales se encuentran:
    • Exactitud (accuracy): indica el porcentaje total de predicciones correctas respecto al número total de predicciones.
    • Precisión (precision): indica qué tan confiables son las predicciones positivas de un modelo. Es decir, de todos los casos que el modelo dijo que eran positivos, ¿cuántos realmente lo eran?, en otras palabras, cuán tan confiable es el "sí" del modelo.
    • Sensibilidad o recall: indica qué proporción de los casos positivos reales consiguió detectar correctamente el modelo. es importante cuando no detectar un caso positivo puede tener consecuencias importantes.
    • Puntuación f1 (f1-score): combina precisión y sensibilidad en una única métrica, buscando un equilibrio entre ambas. resulta especialmente útil cuando existe un desequilibrio entre las clases.
  • Métricas de regresión: se utilizan cuando el modelo debe predecir un valor numérico, como un precio, una temperatura o unas ventas. entre las más utilizadas se encuentran:
    • Error absoluto medio (mae): representa el promedio de la magnitud de los errores entre los valores reales y las predicciones. su resultado se expresa en las mismas unidades de la variable que se está prediciendo y es relativamente fácil de interpretar.
    • Raíz del error cuadrático medio (rmse): calcula la raíz cuadrada del promedio de los errores al cuadrado. al elevar los errores al cuadrado, penaliza con mayor intensidad los errores grandes, por lo que resulta útil cuando estos errores son especialmente importantes.

¿Qué se debe tener en cuenta?

No existe una única métrica que determine por sí sola si un modelo es bueno. la métrica adecuada depende del tipo de problema, de las características de los datos y de las consecuencias que puedan tener los errores.

Por ejemplo, en un sistema médico podría ser especialmente importante detectar la mayor cantidad posible de casos positivos, mientras que en otro sistema podría ser más importante evitar falsas alarmas. por esta razón, la evaluación debe considerar el contexto en el que se utilizará el modelo y no únicamente un valor de precisión o exactitud.

Aplicaciones del machine learning

El machine learning tiene aplicaciones en numerosos sectores porque permite que los sistemas aprendan patrones a partir de datos y utilicen ese aprendizaje para realizar predicciones, clasificaciones, recomendaciones o tomar decisiones.

  • Datos clínicos: identificar factores de riesgo, descubrir posibles nuevos medicamentos y desarrollar tratamientos más personalizados. en estos casos, los modelos sirven como herramientas de apoyo y no necesariamente sustituyen la decisión de los profesionales de la salud.
  • Finanzas: permite detectar operaciones sospechosas o fraudulentas, evaluar el riesgo asociado a determinadas operaciones, analizar el comportamiento financiero y automatizar diferentes procesos de análisis. también se utiliza en sistemas de negociación algorítmica, aunque estos sistemas implican riesgos y requieren controles adecuados.
  • Comercio electrónico: permite analizar el comportamiento de los usuarios para recomendar productos, personalizar contenidos y mejorar la experiencia de compra. por ejemplo, una plataforma puede aprender de las búsquedas y compras anteriores para sugerir productos que podrían resultar de interés.
  • Automoción y transporte: se utiliza para desarrollar sistemas de asistencia a la conducción, analizar el comportamiento del tráfico, optimizar rutas y realizar mantenimiento predictivo. en vehículos y sistemas de transporte, los modelos pueden analizar datos de sensores para detectar posibles problemas antes de que ocurra una falla.
  • Procesamiento del lenguaje natural (pln): permite que los sistemas informáticos trabajen con lenguaje humano. algunas aplicaciones incluyen traducción automática, clasificación de textos, análisis de sentimientos, reconocimiento de voz, generación de texto y asistentes conversacionales.
  • Visión por computadora: permite que los sistemas analicen e interpreten imágenes y videos. sus aplicaciones incluyen reconocimiento de objetos, inspección industrial, análisis de imágenes médicas, sistemas de seguridad y reconocimiento facial, este último con importantes consideraciones relacionadas con privacidad y uso responsable.
  • Industria y manufactura: se utiliza para detectar defectos en productos, controlar procesos, predecir fallas en maquinaria y optimizar la producción. esto permite reducir tiempos de inactividad y mejorar la eficiencia de los procesos industriales.
  • Agricultura: permite analizar imágenes de cultivos, detectar enfermedades en las plantas, estimar rendimientos y optimizar el uso de agua, fertilizantes y otros recursos mediante el análisis de diferentes tipos de datos.
  • Marketing y publicidad: ayuda a identificar patrones en el comportamiento de los consumidores, segmentar audiencias, predecir posibles compras y personalizar campañas de acuerdo con las características y preferencias de cada grupo.

En general, el machine learning resulta especialmente útil cuando existe una gran cantidad de datos y se busca encontrar patrones que serían difíciles de identificar manualmente. Sin embargo, la calidad de los resultados depende de factores como la calidad de los datos, el diseño del modelo y la correcta interpretación de sus resultados.

Retos y consideraciones éticas

El desarrollo y uso de sistemas de inteligencia artificial y aprendizaje automático no solo plantea desafíos técnicos, sino también cuestiones éticas que deben tenerse en cuenta para garantizar un uso responsable y confiable de estas tecnologías.

  • Sesgo en los datos: si los datos utilizados para entrenar un modelo contienen prejuicios, desequilibrios o representaciones insuficientes de determinados grupos, el modelo puede aprenderlos y reproducirlos, e incluso amplificarlos al tomar nuevas decisiones.
  • Privacidad y protección de datos: muchos sistemas de inteligencia artificial utilizan grandes cantidades de información. cuando estos datos contienen información personal, su recopilación, almacenamiento y procesamiento deben realizarse de forma responsable y de acuerdo con las normas de protección de datos aplicables.
  • Explicabilidad y transparencia: algunos modelos, especialmente los más complejos, pueden funcionar como una "caja negra", dificultando la comprensión de cómo llegaron a una determinada predicción o decisión. esto puede ser especialmente importante cuando sus resultados afectan a las personas.
  • Calidad de los datos: datos incompletos, incorrectos, duplicados, desactualizados o mal estructurados pueden afectar directamente el rendimiento del modelo y producir resultados poco confiables.
  • Seguridad: los sistemas de inteligencia artificial deben protegerse frente a errores, manipulaciones, accesos no autorizados y otros riesgos que puedan comprometer la información o alterar sus resultados.
  • Responsabilidad: debe existir claridad sobre quién es responsable de diseñar, implementar, supervisar y corregir un sistema de inteligencia artificial cuando este genera resultados incorrectos o causa consecuencias no deseadas.
  • Supervisión humana: la inteligencia artificial no debería considerarse infalible. en aplicaciones de alto impacto, resulta importante mantener mecanismos de revisión humana que permitan detectar errores, cuestionar resultados y tomar decisiones cuando el sistema no sea confiable.
  • Equidad y no discriminación: los sistemas deben evaluarse para comprobar que sus resultados no generen un trato injusto o discriminatorio hacia determinados grupos de personas.
  • Uso responsable: una herramienta de inteligencia artificial puede utilizarse para diferentes propósitos, pero no todos ellos son apropiados. es necesario establecer límites y criterios que permitan prevenir usos perjudiciales, irresponsables o contrarios a las normas.

En conjunto, estos retos muestran que desarrollar una solución de inteligencia artificial no consiste únicamente en conseguir que un modelo sea preciso. También es necesario garantizar que los datos sean adecuados, que el sistema sea seguro y transparente y que sus resultados puedan utilizarse de manera responsable.

Herramientas para empezar

Para comenzar en el campo de la inteligencia artificial, el aprendizaje automático y el análisis de datos, existe un conjunto de herramientas que permite trabajar desde la preparación de los datos hasta la creación y evaluación de modelos.

  • Python: es uno de los lenguajes de programación más utilizados en ciencia de datos, inteligencia artificial y machine learning. su principal ventaja es la gran cantidad de bibliotecas disponibles para trabajar con datos, modelos matemáticos y redes neuronales.
  • Numpy: proporciona estructuras y funciones para trabajar de forma eficiente con arreglos numéricos y operaciones matemáticas. constituye una de las bases del ecosistema científico de python.
  • Pandas: facilita la carga, limpieza, transformación y análisis de datos mediante estructuras como series y dataframe. es especialmente útil para trabajar con archivos csv, excel y diferentes fuentes de datos.
  • Matplotlib y seaborn: permiten crear gráficos para explorar y visualizar los datos. matplotlib proporciona las herramientas fundamentales de visualización, mientras que seaborn facilita la creación de gráficos estadísticos más elaborados.
  • Scikit-learn: es una de las principales bibliotecas de python para machine learning tradicional. permite implementar algoritmos de clasificación, regresión, agrupamiento, reducción de dimensionalidad y evaluación de modelos sin tener que programar estos algoritmos desde cero.
  • Tensorflow y pytorch: son frameworks utilizados principalmente para deep learning. permiten construir y entrenar redes neuronales para tareas como reconocimiento de imágenes, procesamiento del lenguaje natural y otros problemas complejos de inteligencia artificial.
  • Jupyter notebook: proporciona un entorno interactivo en el que se puede combinar código python, resultados, gráficos y explicaciones en un mismo documento. es especialmente útil para aprender, experimentar y documentar análisis.
  • Google colab: ofrece un entorno similar a jupyter notebook que funciona directamente desde el navegador, sin necesidad de instalar python y muchas de sus bibliotecas localmente. además, puede proporcionar acceso a recursos de hardware acelerado para determinados proyectos de machine learning y deep learning.

¿Cómo se utilizan en conjunto?

Estas herramientas no funcionan necesariamente de manera aislada. en un proyecto típico, el flujo puede comenzar con python y pandas para cargar y preparar los datos, utilizar numpy para operaciones numéricas, emplear matplotlib o seaborn para explorar los resultados, utilizar scikit-learn para desarrollar modelos de machine learning y recurrir a tensorflow o pytorch cuando se necesitan redes neuronales y técnicas de deep learning.

Para una persona que está comenzando, no es necesario aprender todas estas herramientas al mismo tiempo. un camino práctico consiste en comenzar con python, numpy, pandas y matplotlib, continuar con scikit-learn y posteriormente incorporar tensorflow o pytorch cuando ya se tengan fundamentos de programación, análisis de datos y machine learning.

Conclusión

El machine learning es un campo dinámico y en rápida evolución, con el potencial de abordar algunos de los desafíos más complejos de la humanidad. A medida que crece el volumen de datos disponibles y los algoritmos se vuelven más sofisticados, se esperan nuevas innovaciones y aplicaciones transformadoras. Comprender sus principios básicos y sus usos es cada vez más importante en el panorama tecnológico actual.
